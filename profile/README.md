### What we're building

Live graphics shouldn't need a dedicated graphics operator, a broadcast budget or a week of prep. Kinetra is a desktop app for lower thirds, tickers, scoreboards and on-screen graphics that works with the tools you already use: OBS, vMix, CasparCG and anything else that takes a browser source.

- **Design without code.** Build templates visually, start from ready-made styles, or write your own HTML/CSS.
- **Run the show.** Preview, take, update and clear, with tally you can trust on air.
- **Connect your data.** Google Sheets, JSON and CSV APIs, and WebSockets.
- **Play media.** Video, images and audio straight from Kinetra.
- **Output anywhere.** Browser sources, or fullscreen to any connected screen.
- **Control it from anywhere.** A full API, with a Bitfocus Companion module for Stream Deck coming soon.

### Open source

Kinetra is free and open source under the [AGPL-3.0](https://github.com/KinetraLive/kinetra-app/blob/main/LICENSE) license, built the Norwegian way. Bug reports, ideas and contributions are welcome.

Optional **Pro** features (AI-assisted templates and cloud services) help fund development.
